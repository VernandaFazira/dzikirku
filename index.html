Tentang DzikirKu

Aplikasi PWA responsif untuk panduan ibadah harian. Dibuat tanpa backend, murni menggunakan HTML5, Tailwind CSS, dan Vanilla JS (ES6).

Data disematkan secara lokal.

Mode Gelap & Favorit via LocalStorage.

Web Share API & Clipboard Terintegrasi.

Service Worker & Manifest dihasilkan otomatis.
